# Radial Tool Pro (Modern React + Tailwind + Framer Motion)

Aplikasi Desktop Radial Launcher & Smart Context Tools dengan performa tinggi dan desain antarmuka modern.

## Fitur Unggulan
1. **Multi-Layer Radial Navigation**:
   - **Layer Media**: Format Image Langsung, Image to PDF Merge, Smart Screenshot Snip, Kompresi Gambar Batch, dan PDF Split.
   - **Layer Web**: Akses cepat platform kerja dan media (YouTube, Netflix, GitHub, ChatGPT, Google).
2. **Navigasi Cepat (Hold, Aim, Release)**:
   - Tahan tombol trigger, arahkan mouse ke sektor tujuan, dan lepas untuk langsung mengeksekusi aksi.
   - Dilengkapi fungsi pembatalan otomatis di tombol tengah (`✕ BATAL`).
3. **Desain Modern Fluid UI**:
   - Transisi *spring dynamics* yang halus menggunakan Framer Motion.
   - Efek glassmorphism dan backdrop blur modern.
   - Icon vektor tajam berbasis Lucide Icons.

## Stack Teknologi
- **Desktop Runtime**: Electron
- **Frontend Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Animation Engine**: Framer Motion
- **Icons**: Lucide React
